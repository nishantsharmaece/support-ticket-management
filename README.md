# Support Ticket Management

A system for creating, tracking, assigning, and resolving customer support tickets.

## Technology Stack

- **Backend:** .NET (planned)
- **Database:** Relational database (planned)
- **AI-assisted workflow:** Cursor (documentation and prompts in this repository)

Application code and solution files are not yet created.

## Repository Structure

| Path | Purpose |
|------|---------|
| `docs/` | Project documentation |
| `tool-specific/` | Tool-specific configuration and workflows |
| `tool-specific/cursor-workflow/` | Cursor workflow artifacts (context, spec, tasks) |
| `ai-prompts/` | Reusable AI prompts |
| `database/` | Database scripts and schema |
| `.cursor/rules/` | Cursor IDE rules |
